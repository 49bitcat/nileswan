nileswan has been tested with external storage cards up to 32 GiB in size. Storage cards formatted with the FAT16 or FAT32 file system up to 2 TiB in size should be supported as well. **exFAT is not currently supported!**

## Via recovery menu

The most reliable way to format the external storage card is using the on-device recovery menu.

1. Start the console while holding the **X3 + B** button combination (or **Esc + Up** on PCv2). You will enter the cartridge's safe mode.
2. Use up/down buttons to navigate to the **launch recovery** option, then press A (or **Circle** on PCv2).
3. Navigate to **Storage card management**, then to **Format storage card**.
4. Follow the on-screen instructions.
